## 🚀 Инструкции по тестированию

### Сценарий 1: Фильтр по городу
```
1. Открыть приложение
2. Нажать на выпадающий список "🌍 Выберите город"
3. Выбрать "Санкт-Петербург"
4. Поле ввода адреса: ввести "Невский пр"
5. Увидеть только адреса из СПб ✅
```

### Сценарий 2: Маршрут с кнопкой
```
1. Выбрать два адреса в Москве
2. Нажать "Построить маршрут"
3. На карте появятся красные маркеры препятствий
4. Кликнуть на любой красный маркер
5. В popup нажать "🚀 Начать маршрут отсюда"
6. Маршрут строится от текущей позиции ✅
```

### Сценарий 3: Долгое нажатие
```
1. На карте нажать и держать 500мс
2. Появится меню (Мое место / Препятствие / Избранное)
3. Выбрать "Препятствие"
4. Ввести "Потоп в подъезде"
5. Метка сохранится и будет видна как оранжевая иконка ⚠️ ✅
```

### Сценарий 4: Кэширование
```
1. Построить маршрут "Москва" → "Санкт-Петербург"
2. Открыть DevTools → Application → LocalStorage
3. Увидеть ключи: dg_cache_geo_search_*
4. Построить другой маршрут
5. Повторный поиск работает быстрее (из кэша) ✅
```

## ⚠️ Известные ограничения

1. **localStorage ~5-10MB** - хранение меток ограничено
2. **Nominatim rate limit** - 1 запрос в сек без API ключа
3. **Мобильная версия** - долгое нажатие работет на touch devices (нужна доработка)
4. **Offline режим** - только кэшированные данные
